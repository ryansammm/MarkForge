# Welcome to Markdown Workspace

A focused, lightning-fast workspace for connected Markdown notes and documents.

## Key Features

- **Wikilink Navigation**: Jump seamlessly between notes using [[Principles|Writing principles]] or [[Architecture notes]].
- **Client-side Index**: Fast instant search and zero latency document loading.
- **Backlinks Panel**: Discover which documents link back to the current note.

Try clicking on [[Principles]] to explore wikilink resolution!
